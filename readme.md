# Note practice

A drilling tool for practising musical-note recall.

Two modes:

- **Note practice** — shows random sets of notes (with sharps or flats), filtered by rule (Any, Naturals, Fifths, and more). Tap for the next set.
- **Interval practice** — shows a root note plus an interval; tap to reveal the answer note, tap again for the next.

A digital version of a physical flashcard resource.
